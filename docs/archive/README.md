# Archived documents

Files here describe decisions or implementation plans that have since been
superseded. They are preserved to explain history, not as current instructions.

Known replacements:

- `app-meta-kaiplus` was removed. The KaiPlus runtime and LuCI package may
  remain, but KaiPlus is not independently displayed in the software center.
- the proposed `linkeaselite` package was superseded by the small shared
  `linkease-app-entry` package.
- current LinkEase Apps architecture and tests live under `docs/architecture/`
  and `docs/operations/`.
