# FastNet 0.8.8

运行版本 0.8.8-1，LuCI 0.8.8-r1，元包 0.8.8-17。来源目录服务的发布独立处理。

- 卡片结果按 WAN、LAN、NAT / IPv6 排列，改善 LAN 数值、时间与小尺寸显示，支持浅色/深色/跟随系统。
- 包含已验收的多源下载有界恢复、统一默认页面及最多 32 条按项目记录的测速历史；历史不可用不会中断正常测速。
- FastNet 源码提交：`d5063d718233d723769271fb33455e046aff32b8`，标签 `v0.8.8`。
- 运行归档：`fastnet-binary-0.8.8.tar.gz`；SHA256 `c2ce53468e19876c92abdca33358476aeaa15404708e8f45d413c7664bf3fa94`。
- 发布入口：https://github.com/istoreos/istoreos-app-hub/releases/tag/fastnet-runtime-v0.8.8 。

Linux x86_64、aarch64、ARMv7 构建遵循 FastNet Makefile，x86_64 和 ARMv7 使用 UPX，另提供未经压缩的运行归档。Go 全包、LAN 边界/行为/顺序检查通过，新构建前端与内嵌资源逐文件匹配；卡片 18 项浏览器检查及测试机浅深色检查已通过。ARM 仅交叉构建，运行验收为 x86_64。

外部卡片由本目录的 luci-app-fastnet 自有静态资源和注册提供；安装仍沿用原包依赖与注册流程。仅更新核心运行二进制不会替代 LuCI 卡片资源。
