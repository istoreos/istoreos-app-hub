# optimemachine · 时光机

独立运行，依赖 Linkspace 二进制，不依赖 KAI 或 LinkEaseFull。
LuCI：系统 → 时光机；同源入口 `/apps/optimemachine/`；独立 HTTPS 入口按已有设备配置保留。

- 备份版本：完整恢复点与底层 revision，两个层级分别命名；ID 不变。
- 保护记录：Watch 历史、事件、KAI 会话关联；查询不会续租。
- 备份浏览：只读目录、64 KiB 文本预览、历史/当前比较、分段下载。
- 恢复记录：恢复前差异、文件/服务结果及完整日志导出。
- 数据默认保留 60 天，改名不自动固定。卸载包不清理用户仓库和历史。

包钩子不会自动选择磁盘、修改网络或启动全新安装的应用；升级时恢复此前的运行状态。软件中心 start 或用户通过 init 启动并 enable；配置备份位置在独立 UI 完成。原后台本来已停止时，安装流程不擅自启动；不得在保护期间升级。

源码保留在独立 optimemachine 项目；此处只持有 OpenWrt 包装、入口及静态桌面适配。
`release.mk` 中摘要对应本轮本地产物，归档尚未公开发布。通过候选构建工具在本地生成并安装验证；公开源构建前需将相同归档发布到指定 URL 或覆盖下载镜像。

旧版后台与 Linkspace 同时升级时，若 Linkspace 先配置，保留停止与重启标记，等待新版 optimemachine 验证新摘要后恢复运行；不让旧版后台自动信任新二进制。
